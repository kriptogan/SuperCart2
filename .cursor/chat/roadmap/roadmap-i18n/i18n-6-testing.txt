## 🐛 **COMMON ISSUES & FIXES**

### **Issue 1: String Not Translated**

**Symptom:** English text appears in Hebrew app

**Fix:**
1. Find hardcoded string
2. Add to `strings.xml` (all languages)
3. Replace with `stringResource(R.string.xxx)`

---

### **Issue 2: Layout Breaks in RTL**

**Symptom:** UI elements overlap or misaligned in Hebrew

**Fix:**
1. Use `start`/`end` instead of `left`/`right`
2. Test with "Force RTL layout"
3. Adjust padding/margins

---

### **Issue 3: Text Truncates**

**Symptom:** Long Bulgarian text cut off

**Fix:**
```kotlin
Text(
    text = stringResource(R.string.long_text),
    maxLines = 2,
    overflow = TextOverflow.Ellipsis,
    softWrap = true
)
```

---

### **Issue 4: Mixed Text Wrong Direction**

**Symptom:** "iPhone 15" appears reversed in Hebrew

**Fix:**
```kotlin
Text(
    text = "iPhone 15 חדש",
    textDirection = TextDirection.Content  // Auto-detect
)
```

---

### **Issue 5: Language Doesn't Persist**

**Symptom:** App resets to English after restart

**Fix:**
1. Verify `LanguageManager.setLanguage()` is called
2. Check DataStore saving works
3. Verify `attachBaseContext()` loads from DataStore

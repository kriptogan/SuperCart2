1.1. Buying acts the same way the current stores page works when I choose a store:
      - I can search item.
      - I can buy them.
      - view them in "already bought"
      - click "Finish Shopping".
    
1.2. We need to add to the buying mode the folowing:
      - Option to add new grocery item (already linked to the store by default)
      - Show the current date the same way it is visible in the shopping list screen.

1.3. In edit mode:
      - Able to search items.
      - No need to show the date here.
      - Instead of cart icon for the grocery items show an edit icon.
      - Option to add new grocery item (already linked to the store by default)
      - Show edit icon in the top right corner so the user can edit the store info
      - clicking the edit store icon will open the edit store window (the same way it happens from the burger icon in the home screen). * Instead of a small window, make it a full page.
      - The user should be able to change the sub-categories order the same way they are able to do so for the categories.

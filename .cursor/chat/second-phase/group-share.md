# Group Share #

- I want to enable the user the option to share their data with family members.
- If a user wants to share their data, they need the option to generate a serial code that will act as the ID of that group.
- when uploading the data to Cloud, the data should be linked to that serial code.
- A group member will recieve the serial number by any way the origin owner wants to share it, outside of the app.
- A group member will have the option to join the group by inserting the serial number.
- Then, if the serial number is set, and they download the data, they will download only data that is linked to the serial number.
- Serial number is required to upload and download from cloud.
- Any data that is uploaded to cloud considered a shared data, that is shared via serial number.
